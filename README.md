# QueueCTL

Production-inspired CLI background job queue system for Node.js.

Inspired by Sidekiq, BullMQ, Celery, and AWS SQS workers — implemented as a local, SQLite-backed DevOps tool.

> Documentation will be completed as features land. See [DECISIONS.md](./DECISIONS.md) for engineering rationale.

## Quick Start

```bash
npm install
npm run queuectl -- --help
```
